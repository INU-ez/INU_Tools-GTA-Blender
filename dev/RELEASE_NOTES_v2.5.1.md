# v2.5.1: Compiled NODES → Curves → DAT fix

Fixes the incorrect connections (“spider web”) produced by the old Compiled NODES curve exporter. Newly converted curves now retain the source region's physical node identities and export through the same graph/navigation builder as the mesh workflow.

## Fixed

- Preserve vehicle and pedestrian ID order, original directed links, links to neighbouring regions, navigation records and parallel link sections.
- Preserve individual node flags and widths until curve properties are explicitly changed. Lane and traffic-light edits use the spline direction.
- Preserve isolated nodes, cycles and shared junction identities without merging unrelated nearby or coincident original nodes.
- Support Extrude, Subdivide and point duplication in Curve Edit Mode. Subdividing an unambiguous existing segment retains its lanes and direction; new branches default to one lane each way.
- Keep region data in the saved `.blend`, including after the original meshes have been deleted. Selecting one converted chain includes its region's other curves and unconverted categories.
- Reindexing requires all 64 imported regions and updates incoming references. Entire map includes existing imported regions; it no longer fabricates empty neighbouring files.
- Validate the graph and serialize every binary output before replacing destination files. A late disk/OS failure can still interrupt replacement of a batch.

## Existing scenes

Reimport the original Compiled NODES DAT files and repeat **Mesh → Curves**. Curves generated by older versions have no recoverable original identities and remain blocked before writing. Arbitrary curves are also rejected by this exporter.

Keep the hidden `NODES… Curve Source` object. Move shared junction copies together and duplicate points in Edit Mode rather than duplicating whole curve objects. Conflicting shared positions/properties, missing source metadata and duplicate object identities stop export with an explanation.

The curve workflow currently supports the imported 64-region SA grid, including matching FLA4 binary format. Use the mesh exporter for extended region grids.
